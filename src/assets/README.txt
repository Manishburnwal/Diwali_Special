# DEEPOTSAV — Frontend Asset Pack

This pack contains original, scalable SVG illustrations for the Diwali React website.

## Folders
- hero/: hero background and diya visual
- diya/: interactive diya illustration
- fireworks/: fireworks backdrop
- rangoli/: mandala/rangoli ornament
- traditions/: puja thali illustration
- gallery/: sweets illustration
- decorations/: lanterns and marigold garland
- cards/: greeting card frame

## Install
Extract this ZIP, then copy the folders into:
`Diwali_Special/src/assets/images/`

These are SVG illustrations, so they stay sharp at any screen size. You can use them in React with:
`import diya from "./assets/images/diya/diya.svg";`
