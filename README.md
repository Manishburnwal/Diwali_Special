# DEEPOTSAV — A Diwali Surprise from Manish Kumar

A luxury-themed, interactive personal Diwali greeting web application built with React and Vite.

## ✨ Four Main Sections

1. **Hero**: Personalized festive welcome from Manish Kumar with glowing diya animation, gold gradients, and floating particles.
2. **Here Are Your Gifts**: 4 interactive virtual gift cards (**Happiness**, **Prosperity**, **Good Luck**, **Love & Togetherness**) with unwrap interactions and personal blessings.
3. **Light a Diya**: Interactive traditional diya lighting experience with custom flame animations, real-time counter, "Light All" and "Reset" controls, and celebration messages.
4. **A Special Wish For You**: Closing personal blessing and message from Manish Kumar with smooth back-to-top navigation.

## 🛠️ Tech Stack

- **React 19**
- **Vite 6**
- **Tailwind CSS v4**
- **Framer Motion**
- **Lucide React**

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
